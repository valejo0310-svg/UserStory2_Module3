# 📦 README - Práctica de JavaScript

## 📖 Descripción

Este programa en JavaScript practica el manejo de:

* Objetos y arreglos
* Validaciones
* Recorridos con `forEach` y `for...in`
* Uso de `Map` y `Set`
* Métodos como `Object.keys`, `Object.values` y `Object.entries`

---

# 🚀 Funcionalidades

* Crear una lista de productos
* Validar productos
* Mostrar propiedades de objetos
* Guardar datos en un `Map`
* Trabajar con números únicos usando `Set`
* Organizar resultados en consola
